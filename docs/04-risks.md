# Repruv — Top 10 Risks & Mitigations

Ordered by (likelihood × impact) for the first 12 months.

| # | Risk | Why it's real | Mitigation |
|---|---|---|---|
| 1 | **A2P 10DLC registration/throughput blocks SMS at launch** | Carrier registration takes 1–6 weeks; unregistered traffic is filtered. SMS *is* the core workflow. | Submit brand/campaign registration on day 1; conservative initial throughput with carrier-aware rate limiting; email fallback channel built into the sequence engine, not bolted on; Twilio rep engaged before volume ramps. |
| 2 | **Google API access & review-reply eligibility** | Business Profile API access requires approval; replying programmatically needs the customer to grant OAuth on a verified profile. Some accounts won't qualify quickly. | Dual-path ingestion (official API + licensed data vendor); "copy-mode" publishing (one-click copy + deep link) as universal fallback so the AI value lands even without API write access; OAuth grant flow in onboarding. |
| 3 | **AI publishes a damaging response** (admits fault, implies a patient relationship, takes bait from an extortionate reviewer) | One screenshot can kill trust in the category. | Flag taxonomy blocks auto-publish (legal, health/safety, discrimination, extortion, PII); auto-publish defaults to 5★-only and off for healthcare; confidence threshold + daily caps; every published response attributable and retractable; red-team suite of adversarial reviews run in CI against prompt changes. |
| 4 | **Compliance regression — we accidentally build gating** (or customers demand it) | Customers will ask for "only send happy customers to Google." Sales pressure is constant. | Hard product rule: every request includes the public review CTA; private feedback is parallel, never a filter. Positioning leans into it ("audit-proof"). Sales objection kit quantifying the FTC penalty exposure. |
| 5 | **Incumbent response (Birdeye/Podium price cuts or AI catch-up)** | They have distribution and are adding AI. | Win where they're weak: mid-market price point, response *quality* (measurable: edit-rate), agency white-label economics, speed. Publish head-to-head time-to-response and edit-rate benchmarks. Stay narrow (reviews) instead of suite bloat. |
| 6 | **Single-segment concentration / DSO sales cycles slip** | Multi-location deals can take 60–90 days; our 90-day revenue plan leans on them. | Three parallel motions (direct multi-location, agencies, PLG grader tool) so no single pipeline starves us; design-partner discounts to compress first closes; monthly contracts at start (remove procurement friction), annual later. |
| 7 | **Tenant data isolation bug** | Multi-tenant SaaS + agencies viewing child orgs = privilege-escalation surface. A cross-tenant leak is existential at enterprise stage. | All queries through org-scoped data-access layer (no raw table access in handlers); isolation tests in CI (user A cannot read org B fixtures); role checks centralized; pen test before enterprise tier. |
| 8 | **SMS consent / TCPA exposure** | Customers will upload contact lists without lawful consent; fines are per-message. | Consent timestamp required on import (checkbox attestation + per-contact field); STOP/HELP auto-handled and propagated to opt-out ledger; quiet hours enforced server-side; contractual indemnity in ToS; consent-source audit log. |
| 9 | **AI cost/latency surprises at scale** | Per-review analysis + drafting on the top model; a viral customer or polling bug could 50× spend. | Per-org usage metering and budget alarms; idempotent analysis (one row per review); batch API for backfills (50% cost); caching of stable prompt prefix; kill-switch per org; COGS reviewed weekly against gross margin target (>80%). |
| 10 | **Key-person/velocity risk: 2-person team, big surface** | Sequence engine + integrations + AI + billing is a lot; burnout or one departure stalls the roadmap. | Modular monolith with boring tech (one repo, one DB); runbooks from week 1; explicit deferred list (no listings/chat/mobile); hire founding AE at day ~75 to take sales load off founder; weekly scope-cut review — roadmap items get cut before quality does. |

**Standing review:** risks 1–4 are checked weekly in the founder ops review until day 90; the table is re-scored monthly.
