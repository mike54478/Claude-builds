# Repruv — 90-Day Roadmap

Operating assumption: 2 engineers (one is the founder), launch-ready core in 30 days, revenue from day 31, $25–35K MRR by day 90 (on the path to $100K by month 7–9). Every week ships something a customer touches.

## Days 1–30 — "One customer can run their reputation on us"

**Engineering**
- W1: Repo, CI, auth + orgs/memberships, locations CRUD, Stripe checkout/webhooks (per-location quantity), Twilio A2P 10DLC brand+campaign registration submitted (longest external lead time — do first), Neon/Vercel environments.
- W2: Contacts + CSV import with consent fields; review-request state machine + cron scheduler; SMS send with quiet hours + STOP handling; public short-link (`/r/:code`) with dual CTA (Google review / private feedback); private feedback form.
- W3: Google review ingestion (Places API for profile + licensed vendor fallback for full history); reviews inbox UI; Claude analysis pipeline (sentiment/topics/flags) on ingest; AI response drafting with edit-approve flow (copy-to-clipboard publish in v1).
- W4: Overview dashboard (rating trend, request funnel, time-to-response); email fallback channel (Resend); onboarding wizard (connect Google profile → import contacts → brand voice quiz → first campaign); billing portal; hardening + tenant-isolation tests.

**Business (parallel)**
- W1–2: 100-account outbound list (DSOs, HVAC/plumbing rollups, agencies); "free reputation audit" asset generated by our own analysis pipeline.
- W3–4: 15 audit-led demos booked; 5 design partners onboarded at 50% founder pricing, weekly feedback calls.

**Gate to phase 2:** 5 paying orgs, ≥1 with 5+ locations; >95% SMS delivery; first AI drafts approved without edits >60% of the time.

## Days 31–60 — "Multi-location is the product"

**Engineering**
- W5: Org→location roll-up dashboard; location benchmarking (rating, velocity, response SLA vs portfolio median); roles/permissions hardening.
- W6: Auto-publish policy engine (per-location thresholds, flag blocking, daily caps) + Google reply publishing via API for eligible profiles; response queue with bulk approve.
- W7: VoC analytics v1 — topic trends, staff leaderboard, "what changed this month" AI digest emailed weekly; Facebook reviews ingestion.
- W8: Agency mode v1 — parent org switcher, white-label (logo/domain on report pages), client-ready PDF/email monthly report; Zapier app (trigger: job completed → action: send review request) to plug into Jobber/ServiceTitan/Housecall Pro without bespoke integrations.

**Business**
- Case study #1 (vertical: home services) published by day 45; pricing page public; agency partner program (wholesale tiers) launched day 50; outbound shifts 50% to agencies.
- Target: 20 orgs / ~150 locations ≈ **$15–18K MRR** by day 60.

**Gate:** auto-publish enabled by ≥30% of locations with zero retraction incidents; agency channel ≥3 signed partners.

## Days 61–90 — "Scale the motion, deepen the moat"

**Engineering**
- W9: Inngest migration for job processing (volume + retries); rate-limit & cost dashboards per org.
- W10: Yelp ingestion (monitor-only); review widget (embeddable social proof for customer sites — SEO/backlink loop); competitor watch v1 (track N competitor profiles per location, monthly gap report).
- W11: "Review Response Grader" free tool launched (PLG top-of-funnel); public API (API-key auth, requests + reviews endpoints) for agency/enterprise.
- W12: SOC 2 readiness checklist started (vendor selected), data-retention controls, performance pass, on-call/runbook.

**Business**
- 2 more case studies (dental, agency); vertical landing pages; "Reviewnizer/Birdeye alternative" comparison pages; first integration-marketplace listings (Zapier public, Jobber app submitted).
- Hire: 1 founding AE (day ~75) once founder-led playbook converts ≥25% demo→close.
- Target day 90: **45–60 orgs / 280–350 locations ≈ $28–38K MRR**, pipeline ≥ $40K MRR, churn <2%/mo.

## Explicitly deferred (and why)
- ServiceTitan/Dentrix native integrations (Zapier covers v1; build native only when 3+ customers block on it)
- HIPAA BAA / SOC 2 certification completion (readiness only; certify when an enterprise deal demands it)
- Listings management & web-chat widget (incumbent feature bloat; not our wedge)
- Mobile app (responsive web + SMS notifications suffice for v1 personas)
