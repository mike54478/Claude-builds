# Artilagency Website

A modern, futuristic website for Artilagency - a digital marketing agency helping creators monetize their brands.

## Features

- **Futuristic Design**: Dark theme with vibrant gradient accents (purple, cyan, pink)
- **Interactive Animations**:
  - Particle background with mouse interaction
  - Cursor glow effect
  - Floating elements and gradient orbs
  - Smooth scroll animations
  - Card tilt effects on hover
- **Mobile Responsive**: Fully optimized for all screen sizes
- **Contact Form**: Integrated with FormSubmit.co for direct email delivery
- **Performance Optimized**: Lightweight with no external dependencies (except Google Fonts)

## Services Showcased

- Paid Advertising (Meta, TikTok, Google, YouTube)
- Web Design & Development
- Email Marketing
- Organic Social Growth
- Brand Strategy
- Custom Development

## Tech Stack

- HTML5
- CSS3 (Custom properties, Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6+)
- FormSubmit.co for form handling

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. No build process required!

## Deployment

This is a static website that can be deployed to:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting provider

## Contact Form

The contact form submits directly to `michaelakadu@gmail.com` via FormSubmit.co. On first submission, you'll receive a confirmation email to activate the form.
